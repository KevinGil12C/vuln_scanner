Información del Escaneo

VulnScanner Pro realiza evaluaciones de seguridad integrales incluyendo:

  • Escaneo avanzado de puertos con múltiples técnicas
  • Detección de versiones de servicios y captura de banners
  • Coincidencia con base de datos CVE para vulnerabilidades conocidas
  • Referencias cruzadas de bases de datos de exploits
  • Análisis de seguridad de configuración
  • Pruebas de credenciales débiles
  • Escaneo de vulnerabilidades en aplicaciones web
  • Evaluación de seguridad SSL/TLS
  • Fingerprinting y detección de SO
  • Verificación de cumplimiento

VulnScanner Pro

Herramienta Profesional de Análisis de Vulnerabilidades Open-Source

Características

  • Escaneo avanzado de puertos (TCP, SYN, Stealth)
  • Detección de versiones de servicios
  • Integración con base de datos CVE
  • Referencias cruzadas de exploits
  • Auditoría de configuración
  • Pruebas de credenciales débiles
  • Escaneo de vulnerabilidades web
  • Análisis SSL/TLS
  • Fingerprinting de SO
  • Verificación de cumplimiento
  • Reportes profesionales (HTML, JSON, CSV)
  • Priorización de riesgos

Stack Tecnológico

Backend: Python 3.x con framework Eel

Frontend: Bootstrap 5, JavaScript ES6+

Protocolos: TCP/IP, HTTP/HTTPS, SSL/TLS, SSH, FTP, SMTP, y más

Detección de Vulnerabilidades

VulnScanner Pro incluye detección para:

  • CVEs conocidos de los principales proveedores de software
  • Malas configuraciones comunes
  • Mecanismos de autenticación débiles
  • Versiones de software desactualizadas
  • Parches de seguridad faltantes
  • Vulnerabilidades de aplicaciones web (SQLi, XSS, CSRF)
  • Debilidades SSL/TLS
  • Vulnerabilidades a nivel de protocolo
Open Source

Esta es una alternativa open-source a herramientas comerciales como Nessus, OpenVAS y Qualys.

Perfecto para profesionales de seguridad, pentesters y administradores de red.
